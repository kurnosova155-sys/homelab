# Неделя 3: Маршрутизация и коммутация

## 1. VLAN — Virtual LAN

VLAN — виртуальная локальная сеть. Позволяет разделить один
физический коммутатор на несколько логических сетей.

Зачем:
- Безопасность (отделы не видят друг друга).
- Меньше broadcast-шума.
- Гибкость (перенос пользователей без перекоммутации).
- Экономия (не нужен отдельный коммутатор на каждый отдел).

Аналогия: офис с перегородками. Физически все в одном здании,
но каждый отдел видит только своих.

## 2. Access-порт и Trunk-порт

Access-порт — подключён к конечному устройству (PC).
Принадлежит ОДНОМУ VLAN. PC не знает про VLAN,
коммутатор сам добавляет/убирает тег.

Trunk-порт — подключён к другому коммутатору или роутеру.
Передаёт НЕСКОЛЬКО VLAN. К каждому кадру добавляется тег
с номером VLAN, чтобы получатель знал, куда его отправить.

Аналогия:
- Access = почтовый ящик в подъезде (только для одной квартиры).
- Trunk = фургон почты между отделениями (письма для разных квартир).

## 3. Тегирование 802.1Q

802.1Q — стандарт тегирования VLAN.
К кадру добавляется 4-байтный тег с номером VLAN.
Работает только на trunk-портах.

## 4. Как устройства в разных VLAN общаются

Они НЕ общаются напрямую. Нужен роутер.

Роутер НЕ переделывает VLAN 10 в VLAN 20.
Он маршрутизирует пакеты между подсетями,
привязанными к разным VLAN.

Как работает:
1. PC1 в VLAN 10 (192.168.10.1) хочет пингануть PC3 в VLAN 20 (192.168.20.1).
2. PC1 видит, что цель вне его сети → отправляет пакет на gateway.
3. Роутер смотрит в таблицу маршрутизации.
4. Роутер отправляет пакет в VLAN 20.
5. PC3 отвечает.

Router-on-a-stick — один интерфейс роутера делится на подадинтерфейсы,
каждый привязан к своему VLAN.

## 5. Практика 1 — VLAN на одном коммутаторе

Топология:
- PC1, PC2 — VLAN 10.
- PC3 — VLAN 20.
- Switch — 1 коммутатор.

Настройка:
- VLAN 10 и VLAN 20 созданы.
- Fa0/1, Fa0/2 — access VLAN 10.
- Fa0/3 — access VLAN 20.

Проверка:
- PC1 → PC2: работает (один VLAN).
- PC1 → PC3: НЕ работает (разные VLAN, роутера нет).

## 6. Практика 2 — Router-on-a-stick с двумя коммутаторами

Топология:
PC1 ── Switch1 ──trunk── Switch2 ──trunk── Router0
PC2 ──┘                    │
                        PC3 (VLAN 20)
PC1, PC2 — VLAN 10.

Настройка:
- Switch1: Fa0/1, Fa0/2 — access VLAN 10. Fa0/3 — trunk к Switch2.
- Switch2: Fa0/1 — trunk к Switch1. Fa0/2 — trunk к Router0. Fa0/3 — access VLAN 20.
- Router0: Fa0/0.10 — 192.168.10.254. Fa0/0.20 — 192.168.20.254.
- PC1, PC2: gateway 192.168.10.254. PC3: gateway 192.168.20.254.

Проверка:
- PC1 → PC2: работает (один VLAN).
- PC1 → PC3: работает (через роутер).
- PC3 → PC1: работает.

## 7. STP — Spanning Tree Protocol

STP — протокол, который блокирует лишние пути в сети с петлями,
оставляя один активный. Если основной путь упадёт — резервный включится.

Зачем нужен: без STP петля в сети приведёт к broadcast-шторму,
коммутаторы зависнут, сеть упадёт.

### Топология с петлёй

Треугольник из 3 коммутаторов:
- Switch1 ↔ Switch2.
- Switch2 ↔ Switch3.
- Switch3 ↔ Switch1.
- PC1 на Switch1.

Root Bridge — Switch3 (выбран автоматически по Bridge ID).

На Switch1:
- Fa0/2 — Root Port (лучший путь к Switch3).
- Fa0/3 — Alternate Port, Blocking (резервный путь).
- Fa0/1 — Designated Port (к PC1).

### Состояния портов STP

- Blocking — не передаёт, слушает BPDU.
- Listening — слушает BPDU.
- Learning — изучает MAC.
- Forwarding — передаёт.
- Disabled — выключен.

### Поведение при обрыве кабеля

Случай 1: обрыв АКТИВНОГО кабеля.
- STP теряет Root Port.
- Перестройка 30–50 секунд.
- Заблокированный порт разблокируется.
- Трафик идёт по резервному пути.
- Ping теряет пакеты во время перестройки, потом восстанавливается.

Случай 2: обрыв ЗАБЛОКИРОВАННОГО кабеля.
- Он и так не передавал.
- Ничего не меняется.
- Ping не теряет пакеты.

Вывод: STP реагирует только на обрыв АКТИВНОГО пути.

## 8. Что узнала

- VLAN — граница broadcast-домена.
- Коммутатор читает только MAC, роутер — IP.
- MAC получателя меняется на каждом участке, IP — нет.
- Trunk передаёт несколько VLAN с тегами.
- Router-on-a-stick — один интерфейс роутера для нескольких VLAN.
- STP блокирует лишние пути, при обрыве активного — перестраивается.
